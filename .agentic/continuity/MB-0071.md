## Dead ends and rejected approaches

- Letting both lists' order forms post on a move between groups: the source group's order (without the moved id) would be stale until the move is saved, and its answer would race the drop group's. One request is posted instead.
- Treating an order with one extra favorite as a move, without `moved`: it changes MB-0066's route behaviour (its test refuses exactly that order).
